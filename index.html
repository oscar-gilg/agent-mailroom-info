Oscar Agent Mailroom · Privacy

Talk to your agents by email.

Oscar Agent Mailroom connects a dedicated Gmail inbox to Oscar’s Claude Code and Codex sessions. It is personal software for one owner.

Agents send reports as readable HTML emails with optional attachments. Replying continues the conversation with the originating agent. A new email starts a conversation with a shared orchestrator that can coordinate registered sessions.

Google account access

The application requests Gmail access to read instructions, send results, and label messages as they are processed. Only the dedicated agent mailbox is connected. The app checks the sender before forwarding an instruction to an agent.

How messages are handled

Messages and routing records are stored on the owner’s VM. Instructions are passed to the selected agent and may be processed by Anthropic or OpenAI through the owner’s existing subscriptions. The privacy policy describes storage, processing, and deletion.

This website provides application information. It does not provide public access to the mailbox or agents.
